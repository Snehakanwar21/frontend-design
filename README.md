# Frontend Design Project

This is a frontend web development project focused on creating a clean, modern, and user-friendly website design.

## 🚀 Features
- **Responsive Layout:** Works well on both desktop and mobile screens.
- **Multi-page Structure:** Includes multiple interconnected web pages for full navigation.
- **Clean UI:** Modern design elements and structure.

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Pages & Structure
The repository contains the following pages based on the sidebar layout:
- `index.html` - The main homepage of the website.
- `about.html` - Information about the website or business.
- `services.html` - Details of the services provided.
- `rooms.html` - Details regarding room availability and features.
- `booking.html` - Booking and reservation forms.
- `gallery.html` - Photo gallery showcasing images.
- `contact.html` - Contact form and location details.

## 💻 How to Run This Project Local
1. Clone the repository or download the ZIP file.
2. Open the project folder in your code editor (like VS Code).
